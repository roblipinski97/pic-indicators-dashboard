# PIC Indicators dashboard

Public Institutions' Capacity (PIC) Indicators: how governments manage public employment and public finances, from public documents. Pilot data, 2026. World Bank Group (Global Governance).

This folder holds the rendered website only. It is produced from the Quarto project `pic_dashboard` (`quarto render` copies the site here through `prep/copy_to_site_repo.R`); edit the project, not these files.

The answers shown are pilot results from an AI pipeline that are being reviewed by people; they are not official statistics.
